# PRIDE LINE — спортивная аналитика

Одностраничный премиальный лендинг по мудборду PRIDE LINE: чёрно-золотая кинематографичная
идентичность, лев на первом экране, аналитический отчёт как живой HTML-макет, цены, путь
пользователя, FAQ и финальный CTA в Telegram-бот.

- Бот: https://t.me/PrideLine1GateBot
- Регистрация: https://lkga.cc/d1452c
- Промокод: PRIDELINE

## Структура проекта

```
pride-line/
├── index.html               # основной файл сайта (семантическая разметка, 10 блоков)
├── standalone.html          # то же самое одним файлом (CSS/JS/шрифты/картинки внутри)
├── dist/index.html          # копия standalone-сборки для быстрого просмотра
├── assets/
│   ├── css/styles.css       # дизайн-система и вся вёрстка
│   ├── css/fonts.css        # локальные @font-face (Unbounded, Manrope — кириллица+латиница)
│   ├── js/main.js           # меню, FAQ, reveal-анимации, параллакс, копирование промокода
│   ├── fonts/*.woff2        # вариативные шрифты, сайт НЕ зависит от Google Fonts
│   └── img/*.webp           # лев (hero), стадион (атмосфера и отчёт), лев (финал)
├── screenshots/             # скриншоты реально запущенного сайта (Chromium, Playwright)
└── README.md
```

## Запуск локально

Вариант 1 — просто открыть:
```
откройте index.html в браузере (двойной клик)
```
Вариант 2 — локальный сервер (рекомендуется):
```
cd pride-line
python3 -m http.server 8080
# затем откройте http://localhost:8080
```
Вариант 3 — standalone: откройте `standalone.html` — он полностью самодостаточен
(все стили, скрипты, шрифты и изображения встроены), удобен для пересылки одним файлом.

## Публикация

Сайт статический, сборки и зависимостей нет:
- Любой статический хостинг: загрузите содержимое папки (index.html + assets/) в корень
  (Netlify, Vercel, GitHub Pages, Cloudflare Pages, обычный shared-хостинг).
- Или только `standalone.html` одним файлом — переименуйте его в index.html.
- HTTPS рекомендуется (Telegram-ссылки работают с http/https одинаково).

Перед публикацией при необходимости замените ссылки (все встречаются в index.html):
- `https://t.me/PrideLine1GateBot` — CTA «Открыть доступ в боте» и все кнопки бота;
- `https://lkga.cc/d1452c` — ссылка регистрации (блок «Как открывается доступ», футер).

## Что реализовано (по ТЗ)

1. Hero: логотип, крупный заголовок, лев как визуальный центр, подзаголовок, золотой CTA,
   три принципа, маркер 18+.
2. Позиционирование: контраст «Шум против разбора» + схема «хаос → система».
3. Атмосфера: полноэкранный стадион с параллаксом, слои текста и интерфейсная панель.
4. Аналитический продукт: настоящий HTML/CSS-макет отчёта (контекст, форма, тактическая
   схема поля, ключевые факторы со шкалами, круговая шкала, три сценария, риски, вывод,
   состав отчёта). Помечено как пример структуры, демонстрационные данные не выдаются
   за реальные результаты.
5. Разнообразие композиции: строки видов спорта, информационные панели, таблицы-пиллы,
   разные сетки от секции к секции.
6. Методология: шесть шагов 01–06 (данные, контекст, анализ, сценарии, риски, вывод).
7. Продукт и цены: 2 500 ₽ и 10 000 ₽ крупно, состав разбора, «5 разборов — не экспресс»,
   CTA в бот.
8. Бесплатный доступ: 2 бесплатных прогноза в день для участников канала.
9. Путь пользователя: 01 бот → 02 регистрация по партнёрской ссылке → 03 ID и скриншот
   боту → 04 доступ; отдельная кнопка регистрации lkga.cc/d1452c, промокод PRIDELINE
   с кнопкой копирования; условие регистрации не спрятано.
10. FAQ (8 вопросов, рабочий аккордеон) и финальная чёрно-золотая композиция с логотипом,
    CTA, предупреждением 18+ и информацией о рисках.

Техника: адаптив (брейкпоинты 1100/1024/860/640/420), мобильное меню, плавная прокрутка,
reveal-анимации с уважением prefers-reduced-motion, семантика (header/main/section/footer,
aria-атрибуты), доступность с клавиатуры (skip-link, focus-visible, Esc в меню),
title/meta description/OG, favicon, локальные шрифты с системными фолбэками.

## Выполненные проверки (реальные, Chromium headless + Playwright)

- Кнопка копирования промокода: возвращает «Скопировано: PRIDELINE».
- Все золотые CTA ведут на https://t.me/PrideLine1GateBot; ссылка регистрации —
  https://lkga.cc/d1452c (проверено по DOM).
- Шрифты Unbounded и Manrope загружаются локально (document.fonts.check = true).
- Секционные скриншоты: отчёт, цены, путь пользователя, FAQ, меню.

## Известные ограничения

- Скриншоты сделаны в headless Chromium без эмуляции тач-событий; ручная проверка на
  реальном устройстве рекомендуется.
- В app-превью рабочей области внешние файлы могут не подгрузиться — для просмотра
  внутри приложения используйте standalone.html (всё встроено).
- Изображения сгенерированы (лев, стадион) как художественные ассеты бренда.
- Демонстрационные данные в макете отчёта явно помечены как пример.
